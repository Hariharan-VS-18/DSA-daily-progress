## Solution

```
int maxArea(int* height, int heightSize) {
    int i=0,j=heightSize-1;
    int ar=0,max=0;
    while(i<j){
     if(height[i]==height[j]){
        ar=height[j]*(j-i);
        j--;
     }else if(height[i]>height[j]){
        ar=height[j]*(j-i);
        j--;
     }else{
        ar=height[i]*(j-i);
        i++;
     }
     if(max<ar){
        max=ar;
      }
    }
    return max;
}
```

## What I Learned

 Maximum amount of water a container can store is the range between the two pointers.
