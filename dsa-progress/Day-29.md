## Solution

```
class Solution(object):
    def generateParenthesis(self, n):
        res=[]
        def paran(cur,open,close):
            if len(cur)==2*n:
                res.append(cur)
                return
            if open<n:
                paran(cur+'(',open+1,close)
            if close<open:
                paran(cur+')',open,close+1)
        paran('',0,0)
        return res                
        
```
