## Solution

```
class Solution(object):
    def characterReplacement(self, s, k):
        
        freq={}
        l=0
        mfreq=0
        ans=0
        for r in range(len(s)):
            freq[s[r]]=freq.get(s[r],0)+1
            mfreq=max(freq.values())
            while((r-l+1)-mfreq>k):
                freq[s[l]]-=1
                l+=1
            ans=max(ans,r-l+1)    
        return ans
```
