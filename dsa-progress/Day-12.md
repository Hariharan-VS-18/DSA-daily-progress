## Solution

```
class Solution(object):
    def topKFrequent(self, nums, k):
        freq={}
        for n in nums:
            freq[n]=freq.get(n,0)+1;  
        a=sorted(freq.items(),key=lambda x:x[1],reverse=True)
        res=[]
        for x,count in a[:k]:
            res.append(x) 
        return res     
```
